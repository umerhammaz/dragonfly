# Verified LLM Assistant and Model-Family Logos — SVG

This is a reviewed, app-ready subset. Every retained mark was inspected and compared with official model/product branding. The display names in `catalog.json` and `catalog.csv` are the exact app-facing names selected for this package. The SVG `<title>` metadata is aligned to those names for accessibility.

## Use in an app

Read `catalog.json` as the app manifest. Each item has a `name` and a relative SVG path in `icon`. These are product or model-family names—not specific model-version identifiers. For a version-specific model picker, display the provider's exact model/version name separately and do not infer it from the family mark.

## Verified entries

Claude, Gemini, Gemma, DeepSeek, Grok, Kimi, Hunyuan, ERNIE, iFLYTEK Spark LLM, and Amazon Nova. `catalog.csv` records each official brand reference, actual SVG asset source, and what level of brand the mark represents. Tencent's Hunyuan and Baidu's ERNIE SVGs are sourced directly from their official sites.

## Removed after verification

`removed.csv` explains why the previous package's other seven entries were removed. Examples: ChatGPT was paired with OpenAI's provider Blossom mark; Command A / Command R used Cohere's provider mark; Mistral/Mixtral used a provider emblem; Doubao artwork could not be confirmed against the current official app icon. Qwen's artwork could not be established from the official source inspected, so it is omitted rather than guessed.

## Rights

The third-party icon collection's code/assets package is MIT-licensed, but that does not grant rights to each brand's trademark or logo. Official-source assets also remain subject to brand rules. Check each linked official guideline and obtain permission if needed for your app's use. Avoid implying endorsement.
