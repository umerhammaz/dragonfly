# Popular Chat LLM Model Logos — SVG

A deliberately short, recognition-based selection of 17 widely recognized chat LLM families. It removes niche/community and specialized model entries (including OpenChat) from the larger pack.

## Included families

ChatGPT/GPT, Claude, Gemini, Gemma, DeepSeek, Grok, Kimi, Qwen, Mistral/Mixtral, Cohere Command, GLM, MiniMax, Doubao, Hunyuan, ERNIE/Wenxin, Spark, and Nova.

## Scope

This is a shortlist, not a complete LLM directory. Each icon represents a family, not every version. Parent-company-only logos are not substituted for model logos. Llama and Phi are not included because the source collection used here did not provide model-specific marks for them. See `removed.csv` for families removed as niche, specialized, legacy, or lower-recognition.

## Files

- `SVG/` — 17 square SVG marks.
- `catalog.csv` — included families and source details.
- `removed.csv` — removed families and reasons.
- `LOBEHUB-MIT-LICENSE.txt` — upstream project license.
